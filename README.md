# wb-dauerhaft-pro

MQTT-драйвер Wiren Board для приводов штор и жалюзи **Dauerhaft PRO RS-485**.

Демон опрашивает приводы по RS-485 через MQTT-RPC `port/Load` сервиса
wb-mqtt-serial (порт не открывается напрямую — шина делится со штатными
Modbus-устройствами) и публикует по виртуальному устройству на привод по
конвенциям MQTT Wiren Board. К брокеру демон подключается через
`wb_common.mqtt_client.MQTTClient` — по умолчанию через unix-сокет mosquitto,
который остаётся доступен локальным сервисам и после установки пароля на
TCP-листенеры.

Контролы устройства: Открыть / Закрыть / Стоп, поле смены адреса и
индикатор адреса; доступность — через `/devices/<id>/meta/error` (+ LWT).

## Состав

- `Jenkinsfile` — сборка на WB Jenkins (`buildDebArchAll`, пакет `arch: all`).
- `setup.py` + `wb/dauerhaft_pro/` — Python-пакет (неймспейс `wb.`, собирается через pybuild):
  `protocol.py` (кодек кадров), `transport.py` (RPC `port/Load`), `device.py`
  (модель привода), `mqtt.py` (виртуальное устройство WB), `config.py`, `main.py`.
- `bin/wb-dauerhaft-pro` — точка входа; `debian/wb-dauerhaft-pro.service` — systemd-юнит.
- `debian/` — метаданные пакета (`control`, `rules`, `changelog`, `install`, …).
- `configs/wb-dauerhaft-pro.schema.json` — схема для wb-mqtt-confed; создаёт
  страницу конфигурации в веб-интерфейсе.
- `configs/wb-dauerhaft-pro.conf` — конфигурация по умолчанию (пустой список приводов).
- `10wb-dauerhaft-pro` — файл wb-configs (`wb_move`): правки конфигурации
  переживают обновление прошивки и factory reset.

## Сборка

Пакет собирается автоматически на
[jenkins.wirenboard.com](https://jenkins.wirenboard.com) при пуше в ветку или PR.
Локально (в WB-окружении):

```sh
dpkg-buildpackage -us -uc -b
```

## Конфигурация

После установки в веб-интерфейсе контроллера появляется страница конфигурации
(**Настройки → Конфигурационные файлы**). Конфигурация хранится в
`/etc/wb-dauerhaft-pro.conf`.

На странице настраивается список приводов: идентификатор MQTT, название,
тип шторы (рулонная / раздвижная), тип обучения (кнопкой на приводе /
командой через виджет), адрес и порт RS-485. Параметры самого порта драйвер
не задаёт — они определяются настройками порта контроллера, драйвер только
отправляет команды в выбранный порт. Интервал проверки связи (мс) и
отладочные сообщения — опциональные, добавляются через кнопку «Свойства»
редактора.

После сохранения конфигурации wb-mqtt-confed перезапускает демона, и изменения
сразу отражаются в виджетах. Кривой конфиг (включая неуникальные идентификаторы
устройств) — понятная ошибка в журнале и выход с кодом 6 без рестарт-цикла.
Адреса на шине могут повторяться — протокол это допускает, драйвер их не
проверяет.

## Запуск и отладка

Штатно демон запускается systemd-юнитом без аргументов (брокер — unix-сокет).
Для отладки: `wb-dauerhaft-pro -c <конфиг> -b tcp://host:1883 -d`.
