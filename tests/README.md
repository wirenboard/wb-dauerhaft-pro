# Тесты

Автотесты пакета лежат в `tests/` и запускаются pytest-ом из корня репозитория:

```bash
python3 -m pytest tests/
```

Железо и брокер не нужны: проверяется чистый кодек протокола. Эти же тесты
запускает CI.

## Что покрыто

### `tests/test_protocol.py`

Кодек кадров RS-485 (`wb/dauerhaft_pro/protocol.py`):

- сборка запросов байт-в-байт против кадров, записанных с живых приводов на
  стенде (пинг, движение вверх/вниз/стоп, смена адреса);
- разбор реальных ответов: адрес из пинга, эхо команд, подтверждение смены
  адреса (приходит уже с нового адреса) и отказ смены адреса, активный отчёт
  привода, кадр ошибки, неизвестная функция, кадр с пустыми данными;
- режимы ошибок разбора: пакет короче минимума, короче заявленного байтом
  длины, длиннее заявленного (обрезается с предупреждением), повреждённый CRC.
